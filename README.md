    [計價規則
    
    本系統主要用於個人商品及訂單管理，依照實際使用需求採用以下計價方式：
    
    商品單價：以整數元計價，不使用小數價格。
    商品數量：允許小數數量，例如重量商品可使用 0.5 斤。
    金額計算：各品項小計採無條件捨去小數部分，不進行四捨五入。
    訂單總額：將各品項經捨去後的小計加總。
    
    計算範例
    商品單價：33 元／斤
    購買數量：0.5 斤
    計算：33 × 0.5 = 16.5 元
    實際計價：16 元
    
    此規則為配合個人實際使用情境而設計，非一般通用的金額計算方式。]

本專案為個人實際使用需求而自主開發的本機訂單管理系統，目的在於整合商品資料、庫存數量與訂單紀錄，減少人工管理的重複操作，並透過 Web UI 提供直觀的操作介面。

庫存管理規則
- 建立訂單時，檢查商品庫存是否足夠。
- 成功建立訂單後，自動扣除對應庫存。
- 取消尚未取貨的訂單時，回補庫存。
- 已取貨及已取消的訂單不可再透過取消功能回補庫存。
訂單狀態
狀態值	狀態
0	未完成
1	已完成
2	已取貨
3	已取消

        技術	                  目前程式的用途
      SQL 參數化查詢	          避免直接拼接使用者輸入
      
      Transaction	            確保訂單建立與庫存扣除的一致性
      
      commit() / rollback()	  成功提交、失敗時回復交易
      
      SELECT ... FOR UPDATE	  鎖定商品資料，降低同時下單造成庫存競爭的風險
      
      DECIMAL	                處理金額及商品數量
      
      資料表外鍵	              建立訂單、商品及訂單明細的關聯
